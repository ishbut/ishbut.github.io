# 网站维护指南

面向接手维护的学弟/学妹：照着改就能更新内容和上线。

## 1. 基本情况

- 纯静态英文站，Vite 构建，GitHub Pages 托管：https://ishbut.github.io/
- 内容源：`src/content.mjs`（首页、成员、新闻、会议、Access）、`src/recent-work.mjs`（论文）
- 生成器：`scripts/generate.mjs` 生成根目录 HTML。HTML 是生成物，**不要手改**，改 `src/`。
- 唯一部署仓库：`https://github.com/ishbut/ishbut.github.io` 的 `main`，本地 `origin` 已指向它。
- 对外导航只有 4 项：Home / Members（`/staff/`）/ Publications / Access。Conferences、Research、Awards、Patents 页面仍生成，但不在导航里。
- 页面文字一律英文；commit message 一律英文。

## 2. 本地开发

- 双击根目录 `start-local.command` 启动，打开 http://localhost:5173/ 。
- 改 `src/content.mjs`、`src/recent-work.mjs`、`scripts/generate.mjs` 会自动重新生成并刷新浏览器；不用手动 build 或重启服务。
- 唯一例外：往 `public/assets/` **新增**图片后要重启一次 dev server（关掉终端重新双击）才会显示。
- 图片文件名一律小写英文 + 连字符（如 `yunxiao-mu.jpg`），不要用大写，否则线上 Linux 加载失败。
- `dist/` 不提交。

## 3. 改内容

### 导航

改 `src/content.mjs` 顶部：

```js
export const navigation = [['Home','/'],['Members','/staff/'],['Publications','/publication/'],['Access','/services/']];
```

隐藏某栏目但保留页面：从 `navigation` 删掉该项，并确认 `scripts/generate.mjs` 的 `pages` 里对应项有 `label`（否则 `<title>` 会报错）。

### 首页

`home` 常量，三部分：

1. 关键词云 `<section class="keyword-banner">`：`<span class="kw-*">`，`kw-xl/lg/md/sm` 控字号；缩写写全（写 `ARTIFICIAL INTELLIGENCE SECURITY`，别写 `AI SECURITY`）。
2. 居中标语 `<p class="portal-tagline">`：只写 `Institute of Cyberspace Security`，别再加学校名或研究方向。
3. News and Events：来自下面的 `news` 数据。

### News and Events（首页）

`src/content.mjs` 的 `news` 数组，每条四元素：`['月', '日', '年', 'HTML 文本']`，最新在前：

```js
['Nov','26','2026','Our paper was accepted by <a href="..." target="_blank" rel="noopener">...</a>.']
```

只显示在首页。张老师个人页下方展示的是 `books` 里的书，不是新闻。

### 老师（Members）

`src/content.mjs` 的 `members` 数组，每人一个对象。常用字段：

| 字段 | 说明 |
|---|---|
| `slug` | 决定个人页 `/staff/<slug>/` |
| `name` / `role` | 卡片上的姓名与职位 |
| `photo` | 照片路径，放 `public/assets/teachers/` |
| `focus` | 研究方向，缺 `memberTags` 时自动取前两项做标签 |
| `bio` / `contact` | 个人页正文与邮箱 |
| `summary` / `leader: true` | 仅组长（张明武）的横排卡片简介 |
| `detail: profile` | 指向完整个人页 |
| `link` | 卡片改链到外部主页，不再生成个人页 |
| `placeholder: true` | 资料未完善的占位条目 |

- `summary` 和 `profile` 里的简介是两处文字，改一处要同步另一处。
- 卡片标签在 `memberTags` 对象里显式指定，每人最多两个。
- 目前 Yuzhu Wang、Yu Chen 是占位；Yu Chen 卡片链到外部主页。
- 新增老师：加对象 → 放照片（重启一次 dev server）→ 卡片和个人页自动生成。

### 学生

`src/content.mjs` 的 `currentStudents` 数组：`name`、`degree`（`"Master's"` 或 `'Ph.D.'`，页面显示为 `Msc Student` / `PhD Candidate`）、`since`（入学年份）、`link`（姓名外链）、`avatar`、`avatarLink`（头像外链）、`zoom`（头像可放大）。没照片的用姓名首字母占位圆。

排序在 `currentStudentsBlock()`：博士生优先 → 入学年份 → 姓名。

### 论文（Publications）

数据全在 `src/recent-work.mjs`：`recentPapers`（已发表）、`preprints`（Online / Accepted / 预印本）。每条数组：`[年份, 作者, 标题, 期刊会议, 卷期页码, URL, 备注]`。

- 页面只显示 2026 年；Online/Accepted 那组标题显示 `2027`（只改显示，数据年份仍是 2026）。
- 三行排版：标题、作者、期刊+年份+备注。标题不加链接，作者自动缩写为首字母+姓。
- 备注不要写 CCF/JCR/中科院分区。

### Conferences

数据集中在 `src/content.mjs` 的 `HOSTED_CONFERENCE`（名称、slug、全称、主办方、地点、年份）。列表页是一张可点卡片 + 一张不可点的 `ICICS 2026` 占位卡；详情页是轮播 + Welcome + Organizing Committee + Key Dates + News & Updates。路径由 `slug` 决定（如 `css-2026` → `/conference/css-2026/`）。

改 slug 会换 URL，旧生成目录要删掉并提交删除，推送后线上旧页面才移除。

### Access

`src/content.mjs` 的 `services`：地址/联系信息 + 左右两个地图 iframe（左 Google，右高德免 Key 嵌入）。地址不要随意改。

### 页头/页脚与图标

- 模板在 `scripts/generate.mjs`，改一处影响所有页面。
- 图标用 Lucide：在 `src/main.js` 顶部 import 并加入 `createIcons({ icons: {...} })`，HTML 写 `<i data-lucide="arrow-up" aria-hidden="true"></i>`。已用：`arrow-up`、`arrow-up-right`、`arrow-right`、`arrow-left`、`chevron-left/right`、`chevron-down`（移动端 Members 下拉）、`map-pin`、`mailbox`、`mail`。不要用 Unicode 字符当图标。

### 资源与字体

- 老师照片/CV → `public/assets/teachers/`；学生头像 → `public/assets/students/`；校徽、关键词背景、字体 → `public/assets/` 根目录。
- 引用写绝对路径 `/assets/...`，生成器会自动转成相对路径；CSS 里的 `url('/assets/...')` 也保持绝对路径。
- 字体：`aldrich.woff2`（18KB，主用）+ `aldrich.ttf`（老浏览器兜底），配合 `font-display:optional` 和 preload 防止加载时页面抖动。**不要改回 `swap`**。

## 4. 部署

```bash
cd /Users/wangkewen/ishbut
git add -A
git commit -m "Short English summary of the changes"
git push
```

push 到 `origin main` 即发布。Actions 自动 `npm ci` → `npm run build` → 部署 `dist/` → 等 30 秒 → 跑 `scripts/indexnow.mjs` 提交 sitemap 给 IndexNow/Bing。通常 1 分钟内完成。

- `sitemap.xml` 由 `generate.mjs` 自动生成，不用维护。
- `.github/`、`public/robots.txt`、`public/<32位key>.txt` 不要删；`temp.md` 已 gitignore。
- Actions 失败先看日志：构建错通常是 `src/` 改错；IndexNow 那步失败不影响网站本身。

## 5. 提交前自查

- [ ] 改的是 `src/`，不是生成的 HTML
- [ ] 页面文字和 commit message 都是英文
- [ ] 新图片文件名小写+连字符、路径对，且重启过 dev server
- [ ] 改老师简介时 Members 卡片和个人页两处同步
- [ ] 论文无分区注释、标题无链接
- [ ] `sitemap.xml` / `robots.txt` / IndexNow key 没被误删
- [ ] push 后 Actions 成功，线上页面验证过

## 6. 常见问题

**改了内容页面没变？**
确认改的是 `src/` 不是生成 HTML。dev 服务开着会自动刷新，终端看 `[auto-generate]` 日志；仍不行就强刷浏览器（Cmd+Shift+R）。

**新头像不显示？**
文件名用了大写，或新增文件后没重启 dev server。`curl -I http://localhost:5173/assets/students/xxx.jpg` 看 `Content-Type` 是否为 `image/jpeg`，显示 `text/html` 说明文件没被识别。

**子页面（如 `/staff/mingwu/`）样式丢了？**
检查资源路径写法：CSS 里 `url('/assets/...')` 要保持绝对路径。

**新成员页 404？**
`slug` 别有空格或中文；确认 `npm run build` 后生成了 `staff/<slug>/index.html`。

**旧页面还在？**
删掉旧目录后 `git add -A` 提交删除，push 后线上随之移除。
